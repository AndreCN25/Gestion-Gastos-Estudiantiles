# Guion de presentación final - 10 minutos

1. **0:00-1:00 | Problema y usuarios.** Presentar CuentaClara y los roles.
2. **1:00-2:00 | Arquitectura.** Mostrar frontend PWA, FastAPI, SQLAlchemy y PostgreSQL/SQLite.
3. **2:00-4:00 | Flujo estudiante.** Crear cuenta, iniciar sesión, guardar dos gastos, consultar resumen y borrar uno.
4. **4:00-5:00 | Integraciones.** Consultar clima y tipo de cambio; explicar proveedores y límites informativos.
5. **5:00-6:00 | IA.** Pedir recomendación, enseñar que sin clave funciona modo local y con clave se envían solo agregados.
6. **6:00-7:00 | Roles/seguridad.** Probar aislamiento de gastos y mostrar el resumen agregado admin; explicar hash, JWT, validación y variables secretas.
7. **7:00-8:00 | Calidad.** Ejecutar `pytest -q` y mostrar workflow de GitHub Actions en un PR real.
8. **8:00-9:00 | Código y dirección IA.** Recorrer un endpoint y una prueba; presentar bitácoras reales revisadas por integrantes y etiquetas de commits.
9. **9:00-10:00 | Despliegue y preguntas.** Abrir la URL pública ya activada, comentar decisiones y responder preguntas.

Antes de presentar, sustituir los pasos de repositorio y URL por recursos publicados reales; el guion no afirma que ya existan.
